목표 : 기업의 활동, 기업의 주가를 싱크 맞춘 시계열 데이터
의문점 : 밤에 일어나는 활동은 낮 시간의 주가에 어떻게 반영할 것인가?
낮 시간에 일어나는 활동은 즉시 주가에 반영되지만,
밤 시간에 일어나는 활동은 낮 시간의 주가에 반영되지 않는다.

필요한 데이터.
10년간의 한국 100대 기업 주가와 뉴스 리스트
필요한 전처리 : 뉴스를 LLM하여 핵심 키워드를 뽑는다. 즉 그 뉴스로 인한 긍정적인 영향을 미치는 기업과 부정적인 영향을 미치는 기업과 그 크기를 본다.

그 크기를 딥러닝으로 구할 것이고,
초기 9년간의 데이터를 학습하여 이후 1년간의 뉴스를 바탕으로 주가를 추론하는 모델을 작성할 것이다.

해결해야할 의문 - 밤 시간대에 나온 뉴스가 언제 주가에 반영되는가?
가설 제시 :
- 16:00-9:00 사이 뉴스 -> 다음 거래일 오전 주가에 반영
- 09:00-15:30 사이 뉴스 -> 당일 주가에 부분 반영 (시장 효율성 가정)
- 뉴스 공개 시간 정보를 기준으로 시차 보정된 레이블 생성 필요

주가 시계열 데이터 (10년, 일 단위)
- 종가, 시가, 고가, 저가, 거래량 등
- 상장 폐지/변경된 기업 필터링 필요
- 한국 거래소 데이터 API, 금융 데이터 업체 활용
뉴스 데이터 (10년)
- 기사 본문, 발행 시각, 기업명 언급, 섹터, 감성 분석등
- 가능한 출처 : 뉴스 API
