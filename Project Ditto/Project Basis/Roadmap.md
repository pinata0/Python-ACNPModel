# 데이터셋 준비
- KRX 기업 리스트 가져오기
- 네이버 주가에서 10년치 주가 변동 가져오기

# 데이터셋 전처리
- 주가 시계열 데이터를 (주가, 그래디언트) 쌍으로 변환
- 그래디언트는 퍼센트포인트

# 모델 구성
어떤 기업의 그래디언트 변화에 따른 같이 움직이는 그래디언트 분석
이걸 처리하는 새로운 순전파 레이어 구조를 제안해줬으면 좋겠음

## 목표
기업 간 그래디언트 변화 동조성(co-movement)를 기반으로 주가 예측을 한다면, 일반적인 시계열 모델보다 관계 중심 구조가 필요하다.
특정 기업 A의 그래디언트가 변화할 때, 다른 기업들과의 공동 변화를 고려하여 미래 그래디언트를 예측
