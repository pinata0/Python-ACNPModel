## 2️⃣ **전처리 및 시계열 동기화**

|작업|설명|
|---|---|

## 3️⃣ **딥러닝 모델 구조**

### 🧠 **1. 입력 벡터 생성**

- 각 기업별 매일의 입력:  
    `news_embedding + price_feature + meta_data`  
    (예: `[뉴스 임베딩 | 종가 변화율 | 산업 코드 임베딩]`)
    

---

### 🔄 **2. 순전파: 상호작용 추적 레이어 통합**

css

복사편집

`[Agent Sequence Inputs] → [Shared Encoder (e.g., Transformer)] →   → [InteractionTrackingLayer] → [Prediction Head]`

#### 🧩 InteractionTrackingLayer

- 에이전트 간 attention 기반 영향력 추적
    
- `attention[i][j]` = j가 i에게 끼친 영향
    

---

### 🎯 **3. 예측 대상**

- 기업별 다음날 수익률 (회귀) 또는 상승/하락 (분류)
    
- 시계열 형태로 예측 (Multi-step Forecast도 가능)
